about

I write clean code during the day and dense, overlong paragraphs at night. Both are just different ways of trying to get a system to behave.

I'm in my final year of a B.Tech in IT, currently interning as an SAP HCM Consultant at EY in Trivandrum — learning how large organizations encode people into systems, which is either deeply unromantic or exactly the kind of thing I'd write an essay about. My main academic project is an AI-based accident detection system; before that, a calorie-burn prediction model taught me that machine learning is mostly just very patient arithmetic.

Outside of coursework, I build small emotionally-loaded software — apps that track flights, constellations, and relationships with the same rigor you'd bring to a production system — and write personal essays on Substack and LessWrong, usually about the gap between how interfaces are designed and how software actually thinks.

work

ENTRY_01

Droplet

A gamified water-tracking PWA, because apparently I needed a tiny creature silently judging my hydration to actually drink water. Logs intake, levels up a water companion, sends reminders I mostly ignore. Dark mode included so the dehydration looks aesthetic at least.

the real MVP of my kidneys
ENTRY_02

Weatherella

A Discord bot that stalks the weather so I don't have to open an app like a functioning adult. DMs me every morning with the forecast, remembers saved cities, has more personality than most group chats I'm in.

pythondiscord.pyopenweathermap
screams about rain before the rain does
ENTRY_03

Wordly

An Electron Wordle clone I built because opening the actual Wordle website felt like too much commitment. Validates real words against the Datamuse API, keeps an offline fallback list for when the wifi also gives up on me.

electronjavascriptdatamuse-api

Pricehistory

A Python bot that stalks iPhone prices across Flipkart, Amazon, and myG, then messages me on Telegram the second one drops. Logs everything, plots graphs, runs on GitHub Actions because a free cron job beats setting an alarm.

skincare triumphs over suffering

Rail Gate Predictor

Predicts when the level crossing near my house is about to close, mainly so my dad stops getting sun-tanned waiting for trains. Live train data, countdown timers, a map. Built out of love and mild UV concern.

Lost & Found

A lost-and-found board for college, because someone loses their ID roughly every week. Post an item, search for one, get your dignity back (results not guaranteed). Still mid-build — the chaos is catalogued either way.
